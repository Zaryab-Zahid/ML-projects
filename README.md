# ML Projects Repository

A collection of machine learning projects built from scratch while 
learning ML engineering. Each project covers the full pipeline —
data cleaning, EDA, feature engineering, model training and evaluation.

---

## Projects

### Movie Recommendation System
A content-based recommendation engine built on the MovieLens 100K dataset.
Recommends movies based on user rating history and genre similarity using cosine similarity.

- **Dataset:** MovieLens 100K (100,000 ratings, 943 users, 1,682 movies)
- **Techniques:** Cosine Similarity, User-Movie Matrix, Feature Engineering
- **Tech:** Python, Pandas, NumPy, Scikit-learn, Matplotlib
- 📂 [View Project](./Movie%20recommendation%20system)

---

### Titanic EDA
Exploratory data analysis of the Titanic passenger dataset. 
Uncovers patterns about who survived and why through visualizations.

- **Dataset:** Titanic Dataset (891 passengers, 12 features)
- **Techniques:** EDA, Data Cleaning, Visualization
- **Tech:** Python, Pandas, NumPy, Matplotlib
- **Key Findings:** Women 4x more likely to survive, 1st class 2.5x more likely to survive than 3rd
- 📂 [View Project](./Titanic%20EDA)

---

### Customer Churn Prediction
A Random Forest classifier that predicts whether a telecom customer will churn.
Handles imbalanced data and threshold tuning to improve churn detection.

- **Dataset:** IBM Telco Customer Churn (7,043 customers, 21 features)
- **Techniques:** Random Forest, Label Encoding, One Hot Encoding, Threshold Tuning
- **Tech:** Python, Pandas, NumPy, Scikit-learn, Matplotlib
- **Result:** Improved churn recall from 47% to 75% using threshold tuning
- 📂 [View Project](./Customer_Churn_Prediction)

## How to Run Any Project

1. Clone the repository:
```bash
git clone https://github.com/Zaryab-Zahid/ML-projects.git
```
2. Navigate to the project folder
3. Install dependencies:
```bash
pip install numpy pandas matplotlib scikit-learn
```
4. Open the `.ipynb` file in VS Code or Jupyter
5. Run all cells top to bottom
